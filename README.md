### Research Focus: Cybersecurity → AI Vulnerability Detection → Agentic Security Patching

I am a PhD Researcher in Artificial Intelligence and a Senior Systems Architect with over 10 years of software engineering experience. My doctoral research is dedicated to **Cyber Reasoning Systems (CRS)** at the convergence of **Program Analysis, Generative AI, and Automated Program Repair (APR)**.

- **Neuro-Symbolic Vulnerability Detection:** Coupling large language model reasoning with static taint tracking (`CodeQL`, `Semgrep`, AST/CPG representations) to eliminate synthetic hallucinations and achieve high-precision vulnerability discovery across complex C/C++ codebases.
- **Execution-Validated Automated Program Repair (APR):** Building autonomous patching agent loops guided by strict verification oracles—ensuring that proof-of-concept exploits no longer trigger, test suites pass, compiler sanitizers (`ASan`, `UBSan`) report clean executions, and semantic behavior is preserved without regressions.
- **Causal Knowledge Retrieval (Vul-RAG):** Integrating formal vulnerability taxonomies and real-world exploitation intelligence (`CWE`, `CVE`, `CISA KEV`, `EPSS`, `CVSS v4`) into knowledge-grounded retrieval architectures for reproducible vulnerability triage and VEX statement generation.
- **Low-Level Systems & Memory Safety Invariants:** Deep analysis of memory corruption classes (heap/stack buffer overflows, use-after-free, uninitialized memory), binary mitigation mechanisms (ASLR, NX, stack canaries), and Linux operating system internals.
- **Empirical Evaluation on Security Benchmarks:** Rigorous evaluation against contamination-resistant datasets and security benchmark suites (`ARVO`, `SEC-bench`, `PrimeVul`).
